# DigHunter
DirHunter
​DirHunter es una herramienta ligera de reconocimiento web desarrollada en Python, diseñada para descubrir directorios, archivos ocultos y rutas sensibles en servidores mediante fuerza bruta (fuzzing).
​Características
​Escaneo concurrente basado en hilos (ThreadPoolExecutor) para mayor velocidad.
​Verificación automática de extensiones comunes (.php, .html, .txt, .bak, .zip).
​Interfaz interactiva directa desde la terminal.
​Uso exclusivo de librerías nativas de Python (sin dependencias externas).
​Requisitos
​Python 3.x instalado en el sistema.
